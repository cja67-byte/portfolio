# Chigozirim Jesse Amaefule | Personal portfolio

A personal portfolio for a Biomedical Engineering student, built with plain HTML, CSS, and JavaScript. The design uses a metallic-silver and orange background with black text.

## View locally

Open `index.html` in a browser by double-clicking it. No installation or build step is required. VS Code Live Preview can also serve the project.

## Current progress

All five pages are available: Home, About Me, Projects, Skills, and Contact. Projects presents two Python projects from supplied Google Colab notebooks (a currency exchange tracker and a news headline organizer) and a research paper on biocompatibility in prosthetics and implants. Visitors can filter by category, expand project details and original Python code, and download source-only notebook excerpts or the original Word research paper. Home includes two selected project previews. Skills covers developing Python and SQL knowledge, introductory SolidWorks and MATLAB experience, technical and lab skills, professional skills, and languages. Contact provides the approved public email address, cja67@njit.edu, with a direct email link. Testing is documented in [TESTING.md](TESTING.md); full browser and keyboard testing remains incomplete.

## Project sources and presentation

The Python projects are coursework, not live services on this static website. Recorded results come from the supplied notebooks; Python and network requests were not rerun for this presentation. Original selected code is preserved in `assets/notebooks/`, with saved outputs and metadata removed. Open those downloads in Google Colab to inspect or run them. The news exercise requires the user's own `NEWS_API_KEY` environment variable. The weather exercise was excluded because it contains exposed credentials and a recorded authentication failure.

SVG summary graphics in `assets/images/` were created for the portfolio; they are not application screenshots. Project descriptions disclose known implementation limitations. Python downloads may use APIs and local SQLite databases; the website itself uses neither.
